# Trader Sentiment Analytics

## Overview

This project explores the relationship between trader performance and market sentiment to identify patterns that influence trading outcomes. By combining trader activity data with sentiment indicators, the analysis aims to uncover insights that can support more informed trading decisions.



## Objectives

→ Analyze trader performance across different market sentiment conditions

→ Identify correlations between sentiment and profitability

→ Discover behavioral patterns during Fear and Greed market phases

→ Evaluate risk and performance metrics under varying market conditions

→ Generate actionable insights for strategy improvement



## Dataset

### Trader Performance Data

→ Trade history

→ Profit and Loss (PnL)

→ Win/Loss statistics

→ Trade volume

→ Position details

### Market Sentiment Data

→ Fear & Greed Index

→ Market sentiment indicators

→ Volatility metrics

→ Sentiment classification levels

→ Market sentiment has a measurable impact on trader behavior
